# SYNTHETIC dashboard usability review — outline to complete

[Design choice] Ask two or three colleagues arranged by the supervisor to use the dashboard without coaching. Use anonymous participant labels and record elapsed time and hesitation; do not put personal names or firm/client information in the project.

[Design choice] Suggested five questions:

1. Which CSF function currently has the lowest control health, and which controls contribute to it?
2. Which control is overdue for testing, and what evidence explains the alert?
3. Select likelihood5 and impact5: which risk records are in that cell, and how do you export them?
4. Which month has the most incidents, and which severities make up that total?
5. Find the consecutive-failure alerts and identify the test records that caused them.
